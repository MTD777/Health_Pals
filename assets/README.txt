Put the app icon here.

Save your icon as either of these (icon.ico is preferred, PNG works fine too):

  assets/icon.ico     (multi-resolution 16/32/48/256 — sharpest on the taskbar)
  assets/icon.png     (1024x1024 recommended)

HealthPals loads it automatically on the next launch — no rebuild needed.
The file is picked up by src/health_pal/branding.py.
